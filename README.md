# 涂泊酒店 · 营收台账 & 收支利润系统（演示版）

一个为单体酒店做的内部财务小系统：前台每天录营收、交班对账，店长每月录成本、看利润。纯前端实现，打开网页即可使用。

> **这是演示版**：页面上的所有数字都是按当前日期自动生成的虚构数据，不是任何酒店的真实经营数据。
> 访客录入的内容只保存在访客自己的浏览器里。

## 在线体验

- 前台营收台账：`index.html`
- 店长收支利润：`finance.html`

## 功能

**前台营收台账**
- 每日营收按渠道录入（门店 POS / 现金 / 携程 / 美团 / 飞猪 / 抖音 + 便利店、小商品、早餐等）
- 自动计算入住率、平均房价、RevPAR，并与去年同月对比
- 早班 / 晚班交班收款（微信 / 支付宝 / 现金 / 挂账），自动与前台应收对账
- 月度对比折线图、月度汇总表，导出当月 Excel（营收 + 交班明细）

**店长收支利润**
- 月度成本录入（结构与酒店利润表一致，可复制上月）
- 总营收、总成本费用、净利润、毛利率、净利率看板
- 成本结构环形图、月度利润趋势柱状图、月度收支汇总
- 生成并导出月度利润表，导入前台导出的 Excel

## 技术

- HTML + CSS + 原生 JavaScript，无框架、无后端
- 数据保存在浏览器 localStorage
- 图表用原生 SVG 绘制；Excel 导入导出用 [SheetJS](https://sheetjs.com/)
